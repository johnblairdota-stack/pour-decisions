## Where they come from

- Register: Economic Development Queensland (EDQ) "Development Assessment" register (PDA development approvals). Each application page is `https://edqdad.dsdip.qld.gov.au/developmentAssessments/view/front/<id>/`. Each file is `https://edqdad.dsdip.qld.gov.au/developmentAssessments/attachments/view/<file id>/`.
- Northshore Hamilton is a Priority Development Area (PDA). So EDQ (the state) decides the applications, not Brisbane City Council. I did not search council's PD Online, because council does not assess development in the PDA.

## Important finding: no public Riverlight architecture drawings

- Riverlight (Frasers Property, 320 MacArthur Ave, built about 2016–2020) did **not** get its own building approval on this register.
- It was built under the old master approval **DEV2009/007** (Australand, 2009; changed 2012 and 2017). That approval only fixes a "building envelope" (zones and storeys).
- Condition 5 of DEV2009/007 says each building's design (elevations, heights, facades, colours) is "endorsed" by EDQ later, outside the register. Those endorsed drawings are **not public** on the register.
- I scanned all 1,500 public application pages. The only Frasers applications at 310–320 MacArthur Ave are two lot-boundary ones (DEV2016/748 and DEV2016/767).
- To get the real Riverlight elevations, John could ask EDQ Development Assessment (contact details on https://www.edq.qld.gov.au) for the Condition 5 endorsed plans for DEV2009/007, Riverlight stages. They may say no, or ask for a fee or a Right to Information request.
